# Нур Ислам — подготовка расписания

Программа в браузере для администратора мечети. В ней собирают годовое расписание намазов, икамат, Рамадан и объявления, затем скачивают два файла для приложения Нур Ислам на телевизоре и телефоне.

Учётная запись не нужна. Данные мечети остаются в этом браузере и никуда не отправляются. После первой загрузки страница работает без сети.

Как пользоваться без установки, описано в [docs/rukovodstvo.md](docs/rukovodstvo.md).

## Запуск для проверки

Нужны Node.js 22 и npm.

```bash
npm ci
npm run dev
```

Страница откроется на `http://127.0.0.1:4173`.

```bash
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run build
```

`npm run build` собирает готовую папку `dist`. Её можно открыть любым статическим сервером. `npm run preview` показывает уже собранную папку.

Учебные файлы с вымышленными временами лежат в `examples/`. Это не расписание для намаза. Повторить их можно командой `npm run examples`.

## Публикация страницы

Сборка статическая, отдельный сервер не нужен. Автоматической публикации нет: выкладка на основной адрес — отдельное решение владельца.

Чтобы выложить черновик на GitHub Pages:

1. В репозитории включите Pages и выберите источник «GitHub Actions».
2. На вкладке Actions запустите workflow «Страница» вручную.
3. Адрес появится в настройках Pages. Для адреса вида `https://<пользователь>.github.io/<репозиторий>/` текущая сборка уже подходит: пути относительные.

Пока workflow не запускали, публичного адреса нет.

## Что скачивается

Только два файла, которые читает приложение Нур Ислам 0.4:

- `prayer-schedule-ГОД.json` — намазы на год
- `mosque-calendar.json` — икамат, Рамадан и объявления

«Скачать всё» кладёт оба файла и короткую инструкцию в один архив. Копия проекта для этого браузера — отдельный файл и в приложение не загружается.

Подходит таблица Казани: лист с номером года, заголовки во второй строке, город в первом столбце, уже посчитанные значения в ячейках. Формулы программа не считает. Произвольный Excel не обещается.
